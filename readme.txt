Chiusure dell'attività (ferie, feste, ponti, chiusure straordinarie) mostrate ai visitatori con un popup leggero e compatibile con la cache delle pagine.

== Description ==

Il cliente inserisce le chiusure dal menu "Chiusure" della bacheca. Il popup appare da solo nei giorni di preavviso e durante la chiusura, con icona e testi per tipologia. Funziona anche con WP Rocket, LiteSpeed e altre cache: la data si confronta nel browser. Nessuna dipendenza, nessun jQuery nel sito, script sotto i 4 KB. Facoltativo: dati strutturati per Google con gli orari speciali.
